# Cornerstone Website Redesign

A modern redesign of the Cornerstone Group website built as an interview project using Next.js, TypeScript and Tailwind CSS.

## Features

- **Modern Hero Section:** High-resolution product showcase featuring the Menikini MK 4000 industrial dry steam sanitisation equipment.
- **Product Catalog & Detail Pages:** Full responsive product catalogue with dedicated dynamic detail routes (`/products/[slug]`).
- **Core Sectors & Categories:** Comprehensive category sections covering Pest & Disinfection, Hygiene, Power & Energy, Health & Wellness, Infrastructure, Water Solutions, Super Cooling, and Real Estate.
- **Video Gallery:** Integrated video showcase with authentic case studies and applications.
- **Optimized Media:** High-performance WebP assets with Next.js Image component optimization.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build & Production

To create a production build:

```bash
npm run build
```

To run the production build locally:

```bash
npm run start
```
